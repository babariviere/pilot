## Fixture and acceptance discipline

Use isolated temporary stores, faux providers and deterministic held-response/async gates at real ownership boundaries. Release each owned gate, child, subscription, socket and writer and await teardown even on failure. Do not fix failures with retries, longer sleeps, disabled assertions or skips. Inject before and after durable admission and observe disk/receipt, not only mocks or UI state. Assert exact immutable intent, operation identity, target, host/lineage and newer editable text. Assert FIFO mutation order and no second Store writer.

A baseline-negative control must fail the old behavior for the intended reason and pass the changed behavior. If temporarily restoring source, verify bytes, force recompilation as needed and verify the test census: preserving timestamps can reuse a stale binary. Record exact revision, command, dependencies, result, skips and runner limits. Synthetic transports expose ordering faults but do not prove native input, UI frames, actual process lifecycle or a deployed installation. Native and integration qualification must exercise the relevant real boundary.
